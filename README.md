# Hill Sprint Coach

A mobile hill-sprint interval timer for Kenilworth Avenue, Gloucester, to run alongside Strava.

The web app supports mixed power and conditioning intervals, pause/resume, Ready Now, sound cues and screen wake lock where available.

See `index.html` for the app, and `.github/workflows/deploy.yml` for GitHub Pages deployment.

**iPhone limitation:** vibration is generally unavailable in Safari and audio cannot reliably play while the phone is locked or the app is in the background. Keep the web app visible while using it.
